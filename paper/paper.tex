\begin{abstract}
Modern transformer-based Large Language Models (LLMs) face two fundamental scaling walls: the quadratic $O(N^2)$ computational complexity of dense softmax self-attention, and the linear $O(N)$ high-bandwidth memory (HBM) growth of key-value (KV) caches during autoregressive decoding. In this paper, we introduce \textbf{WEFT} (\textbf{W}indowed \textbf{E}xponentially-decayed \textbf{F}actorized \textbf{T}ensor Attention), a dual-path sequence architecture that replaces dense pairwise attention with a local sliding-window softmax operator coupled with a continuous, multi-head exponentially-decayed low-rank tensor recurrence. The recurrent updates are computed entirely within on-chip GPU SRAM tiles, avoiding the materialization of state trajectories in global memory. Furthermore, we extend the tensor uncrossing factorization to neural network parameters via \textbf{Associative Memory Weights (AMW)}, substituting static dense feed-forward networks (MLP) with a fast, rank-factorized associative memory lookup.

Empirical validation on NVIDIA GPU hardware demonstrates: (1) strict $O(N)$ linear time complexity with a \textbf{430.7x speedup over PyTorch FlashAttention (SDPA) at $N = 524{,}288$}, with linear streaming throughput of \textbf{13.25 Million tokens/second in $\sim$520~MB VRAM} (extrapolating to 1-billion tokens in under 1.3 minutes); (2) constant $O(1)$ memory consumption during decoding with a flat \textbf{16~KB to 128~KB recurrent state per layer} and bounded sliding-window KV buffer; (3) syntax and fluency restoration via learnable exponential gating; (4) a \textbf{5.2x parameter reduction} in feed-forward layers with \textbf{1.52x faster training throughput} and near loss parity (7.99 vs 8.05 held-out loss) on FineWeb-Edu; and (5) low-memory training via Muon optimization, reducing optimizer states from 16 bytes/param to 2 bytes/param.
\end{abstract}

\section{Introduction}
Dense multi-head self-attention computes pairwise affinities across all tokens in a sequence:
\begin{equation}
\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V
\end{equation}
While expressive, this formulation enforces an $O(N^2)$ computational complexity during training and requires caching all historical key-value vectors in GPU memory during autoregressive generation ($O(N)$ memory). For sequence lengths exceeding 100,000 tokens, the KV-cache dominates GPU High-Bandwidth Memory (HBM), choking serving concurrency and necessitating complex paging and eviction heuristics.

Simultaneously, standard Feed-Forward Networks (MLPs) account for roughly two-thirds of total model parameters. Evaluating dense linear layers for every token incurs massive memory bandwidth pressure, shifting modern inference into memory-bound regimes.

To resolve these twin bottlenecks, we present \textbf{WEFT}, which combines:
\begin{enumerate}
    \item A \textbf{dual-path attention operator} combining local sliding-window softmax with SRAM-fused low-rank recurrence.
    \item \textbf{Associative Memory Weights (AMW)}, applying tensor-network uncrossing to parameter space.
    \item A complete, production-ready \textbf{Hugging Face and OpenAI-compatible serving engine}.
\end{enumerate}

\section{Mathematical Architecture}

\subsection{Discrete Tensor Uncrossing and the Low-Rank Principle}
The foundational intuition of WEFT originates from discrete planar tensor networks. The single-bit swap operator decomposes algebraically as:
\begin{equation}
\text{SWAP} = I - s s^T
\end{equation}
where $s = [0, 1, -1, 0]^T$ represents unnormalized singlet coefficients (or $\text{SWAP} = I - 2|s\rangle\langle s|$ with $|s\rangle = \frac{|01\rangle - |10\rangle}{\sqrt{2}}$ in normalized quantum representation). This establishes that complex network entanglements can be factored into an identity backbone minus low-rank outer products.

\subsection{Continuous Neural Formulation}
In continuous space, WEFT decomposes the sequence attention matrix into:
\begin{itemize}
    \item \textbf{Local Diagonal Window ($j \ge i - W$):} Evaluates standard softmax attention over a bounded window $W \in \{64, 128\}$ tokens.
    \item \textbf{Global Off-Diagonal Recurrence ($j < i - W$):} Uses positive feature maps $\phi(x) = \text{ELU}(x) + 1$ and updates a recurrent state $S_t \in \mathbb{R}^{H \times R \times D}$:
    \begin{align}
    S_t &= \gamma_t \odot S_{t-1} + k_t^T x_t \\
    y_t &= \frac{1}{\sqrt{R}} \left(v_t \cdot S_t\right)
    \end{align}
    where $R \ll N$ is the configurable state rank ($R \in \{16, 32, 64, 128, \dots, 4096\}$) and $\gamma_t = \sigma(\text{decay\_logits}) \in (0, 1)$ prevents memory drowning.
\end{itemize}

\subsection{Associative Memory Weights (AMW)}
Rather than evaluating dense static parameter matrices $W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$, WEFT-AMW formulates feed-forward compute as an associative dictionary lookup:
\begin{equation}
M(x) = \text{Softmax}\left(\frac{\text{Encoder}(x) K_w^T}{\sqrt{R_{\text{amw}}}}\right) V_w
\end{equation}
where $K_w \in \mathbb{R}^{M \times R_{\text{amw}}}$ and $V_w \in \mathbb{R}^{M \times D}$. The final output is gated: $y = \text{LayerNorm}(x + \sigma(W_g x) \odot M(x))$.

\section{Conclusion}
WEFT demonstrates that sub-quadratic linear attention and sub-linear memory decoding can be combined with parameter-efficient associative weights. By unifying local windows with SRAM-fused recurrence and uncrossed associative parameters, WEFT provides a scalable path forward for long-context sequence modeling on accessible hardware.

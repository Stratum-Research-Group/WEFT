\begin{abstract}
Modern transformer-based Large Language Models (LLMs) face two fundamental scaling walls: the quadratic $O(N^2)$ computational complexity of dense softmax self-attention, and the linear $O(N)$ high-bandwidth memory (HBM) growth of key-value (KV) caches during autoregressive decoding. In this paper, we introduce \textbf{WEFT} (\textbf{W}indowed \textbf{E}xponentially-decayed \textbf{F}actorized \textbf{T}ensor Attention), a dual-path sequence architecture that replaces dense pairwise attention with a local sliding-window softmax operator coupled with a continuous, multi-head exponentially-decayed low-rank tensor recurrence. The recurrent updates are computed entirely within on-chip GPU SRAM tiles, avoiding the materialization of state trajectories in global memory. Furthermore, we extend the tensor uncrossing factorization to neural network parameters via \textbf{Associative Memory Weights (AMW)}, substituting static dense feed-forward networks (MLP) with a fast, rank-factorized associative memory lookup.

Empirical validation on NVIDIA GPU hardware demonstrates: (1) strict $O(N)$ linear time complexity with a \textbf{16.7x speedup over causal PyTorch FlashAttention (SDPA) at $N = 524{,}288$} (733.1~ms vs. 12.26~s with exact backend \texttt{FLASH\_ATTENTION} and causal masking), with an unbroken continuous \textbf{1-Billion Token hardware execution in 72.26s at 13.84 Million tokens/second in 648.3~MB VRAM} (prior extrapolation: 75.48s at 13.25M tok/s); (2) constant $O(1)$ memory consumption during decoding with a flat \textbf{16~KB to 128~KB recurrent state per layer} and bounded sliding-window KV buffer; (3) syntax and fluency restoration via learnable exponential gating; (4) a \textbf{5.2x parameter reduction} in feed-forward layers with \textbf{1.50x faster training throughput} and near held-out loss parity (8.46 vs 8.51, $\Delta=0.052$) on FineWeb-Edu; and (5) low-memory training via Muon optimization, reducing optimizer states from 16 bytes/param to 2 bytes/param.
\end{abstract}

\section{Introduction}
Dense multi-head self-attention computes pairwise affinities across all tokens in a sequence:
\begin{equation}
\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V
\end{equation}
While expressive, this formulation enforces an $O(N^2)$ computational complexity during training and requires caching all historical key-value vectors in GPU memory during autoregressive generation ($O(N)$ memory). For sequence lengths exceeding 100,000 tokens, the KV-cache dominates GPU High-Bandwidth Memory (HBM), choking serving concurrency and necessitating complex paging and eviction heuristics.

Simultaneously, standard Feed-Forward Networks (MLPs) account for roughly two-thirds of total model parameters. Evaluating dense linear layers for every token incurs massive memory bandwidth pressure, shifting modern inference into memory-bound regimes.

To resolve these twin bottlenecks, we present \textbf{WEFT}, which combines:
\begin{enumerate}
    \item A \textbf{dual-path attention operator} combining local sliding-window softmax with SRAM-fused low-rank recurrence.
    \item \textbf{Associative Memory Weights (AMW)}, applying tensor-network uncrossing to parameter space.
    \item A complete, production-ready \textbf{Hugging Face and OpenAI-compatible serving engine}.
\end{enumerate}

\section{Mathematical Architecture}

\subsection{Discrete Tensor Uncrossing and the Low-Rank Principle}
The foundational intuition of WEFT originates from discrete planar tensor networks. The single-bit swap operator decomposes algebraically as:
\begin{equation}
\text{SWAP} = I - s s^T
\end{equation}
where $s = [0, 1, -1, 0]^T$ represents unnormalized singlet coefficients (or $\text{SWAP} = I - 2|s\rangle\langle s|$ with $|s\rangle = \frac{|01\rangle - |10\rangle}{\sqrt{2}}$ in normalized quantum representation). This establishes that complex network entanglements can be factored into an identity backbone minus low-rank outer products.

\subsection{Continuous Neural Formulation}
In continuous space, WEFT decomposes the sequence attention matrix into:
\begin{itemize}
    \item \textbf{Local Diagonal Window ($j \ge i - W$):} Evaluates standard softmax attention over a bounded window $W \in \{64, 128\}$ tokens.
    \item \textbf{Global Off-Diagonal Recurrence ($j < i - W$):} Uses positive feature maps $\phi(x) = \text{ELU}(x) + 1$ and updates a recurrent state $S_t \in \mathbb{R}^{H \times R \times D}$:
    \begin{align}
    S_t &= \gamma_t \odot S_{t-1} + k_t^T x_t \\
    y_t &= \frac{1}{\sqrt{R}} \left(v_t \cdot S_t\right)
    \end{align}
    where $R \ll N$ is the configurable state rank ($R \in \{16, 32, 64, 128, \dots, 4096\}$) and $\gamma_t = \sigma(\text{decay\_logits}) \in (0, 1)$ prevents memory drowning.
\end{itemize}

\subsection{Associative Memory Weights (AMW)}
Rather than evaluating dense static parameter matrices $W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$, WEFT-AMW formulates feed-forward compute as an associative dictionary lookup:
\begin{equation}
M(x) = \text{Softmax}\left(\frac{\text{Encoder}(x) K_w^T}{\sqrt{R_{\text{amw}}}}\right) V_w
\end{equation}
where $K_w \in \mathbb{R}^{M \times R_{\text{amw}}}$ and $V_w \in \mathbb{R}^{M \times D}$. The final output is gated: $y = \text{LayerNorm}(x + \sigma(W_g x) \odot M(x))$.

\section{WEFT-2 Foundation Architecture: Scaling to 589M}
We scale the WEFT framework to a 589M parameter foundation model ($d=896$, 16 layers, 16 routed MoE experts with top-2 active selection, 1 shared expert; 590.9M exact parameters) incorporating Multi-Head Latent Attention (MLA), Dual-Axis Memory Initialization (DAMI), Titans surprise-gated fast weights with $2\times 2$ coupled affine updates, and associative needle-in-a-haystack MoE routing.

\subsection{Architectural Formulation}
WEFT-2 introduces four core architectural subsystems:
\begin{enumerate}
    \item \textbf{Latent Multi-Head Latent Attention (MLA):} Compresses local sliding-window key-value projections into low-rank latent vectors ($d_{\text{latent}} = 192$), reducing projection parameter count and enabling resident latent KV cache storage. During generation, resident cache compression yields a $21.3\times$ memory reduction compared to standard expanded multi-head KV caches.
    \item \textbf{Dual-Axis Memory Initialization (DAMI):} Establishes multi-scale memory retention by initializing recurrence decay rates geometrically across heads and layers from short-term ($\tau = 64$ tokens) to persistent long-term ($\tau = 65{,}536$ tokens).
    \item \textbf{Titans Surprise-Gated Fast Weights with Coupled Affine Updates:} Integrates test-time neural plastic weights $W_{\text{fast}}$ driven by prediction surprise ($\text{error} = k W^T - v$). The momentum and weight dynamics are formulated as a coupled affine operator across sequence chunks:
    \begin{equation}
    \begin{pmatrix} m_t \\ W_t \end{pmatrix} = \begin{pmatrix} \eta_t I & 0 \\ \eta_t I & (1 - \gamma_t) I \end{pmatrix} \begin{pmatrix} m_{t-1} \\ W_{t-1} \end{pmatrix} + \begin{pmatrix} -\nabla W_t \\ -\nabla W_t \end{pmatrix}
    \end{equation}
    enabling chunk-batched plastic memory adaptation with online per-token updates during autoregressive decode with zero state divergence ($< 5.96 \times 10^{-8}$ absolute difference between chunked prefill and single-token decode under matched schedules).
    \item \textbf{Associative Needle-in-a-Haystack MoE Routing:} Rather than static token-wise routing projections ($W_r x_t$) that lose access to early context over long horizons, WEFT-2 equips each MoE layer with an outer-product associative router memory:
    \begin{equation}
    R_t = \gamma_{\text{router}} R_{t-1} + k_{r, t-1}^T \text{SoftAssignment}_t
    \end{equation}
    maintaining dynamic historical expert allocations across the generation cache.
\end{enumerate}

\subsection{Post-Training Quantization (PTQ) \& Fused SRAM GEMM Decoding}
To enable edge serving on memory-constrained GPUs without degrading numerical precision, WEFT-2 introduces native per-channel INT8 Post-Training Quantization (PTQ):
\begin{itemize}
    \item \textbf{Memory Compression:} Compresses full model parameters from \textbf{1,127.10~MB} (bfloat16) down to \textbf{649.62~MB} (INT8 weights with bfloat16 scales and biases)---an exact \textbf{1.74x memory footprint reduction}.
    \item \textbf{Fidelity Preservation:} Across deep context evaluations, INT8 quantization achieves an exceptional logits cosine similarity of \textbf{0.999137} ($>0.99$ target) with maximum absolute logits deviation bounded at $1.0312$.
    \item \textbf{Triton SRAM-Fused INT8 GEMM:} Loads INT8 weights directly from high-bandwidth DRAM into GPU registers and executes in-register float conversion prior to matrix-vector accumulation, halving weight read bandwidth and maintaining full equivalence ($>0.99999$ cosine similarity against cuBLAS baseline).
    \item \textbf{Paged Latent Cache Serving:} Paired with a 16-token non-contiguous block manager for resident MLA latents ($d_{\text{latent}}=192$), serving memory per active stream is bounded to under 96~MB across 1,024 blocks, eliminating memory fragmentation under concurrent workloads.
\end{itemize}

\subsection{Reinforcement Learning with Rule Verifiers (GRPO) \& Systems Acceleration}
WEFT-2 was aligned on multi-step reasoning via Group Relative Policy Optimization (GRPO / RLVR) with deterministic verification rules:
\begin{itemize}
    \item \textbf{CUDA Graph Recurrent Replay:} By eliminating dynamic CPU-GPU dispatch synchronizations within DeepSeekMoE routing, the entire 16-layer, 590M parameter model single-token recurrent decode step was captured in a static CUDA Graph. This reduced 300-episode rollout wall-clock time from 8,056~s ($\sim 2.24$ hours) to \textbf{1,049~s ($\sim 17.5$ minutes)}---a \textbf{7.67x wall-clock speedup}.
    \item \textbf{Strict $O(1)$ Rollout Memory:} VRAM remained flat across all 1,200 generation rollouts at \textbf{5,775~MB to 5,973~MB}, verifying zero memory leaks or cache bloating during extended policy training.
    \item \textbf{Latent Resident MLA Cache Parity:} Latent resident caching stores only the compressed 192-dimensional latent representation rather than expanding full 4,096-dimensional key/value projections, delivering a \textbf{21.3x resident KV cache compression ratio} while matching expanded numerical outputs to $< 3.6 \times 10^{-7}$ precision.
\end{itemize}

\subsection{Frontier Systems Acceleration: Triton FlashDecoding, BitNet b1.58 \& Speculative Decoding}
Recent engineering extensions further solidify the deployment and execution efficiency of WEFT-2:
\begin{itemize}
    \item \textbf{Triton FlashDecoding Fast-Path:} We implemented a custom fused decode operator (\texttt{weft\_decode\_step\_triton}) in Triton that maintains the recurrent state $S_t = \text{diag}(\sigma(\gamma)) \cdot S_{t-1} + k_t^T x_t$ entirely within GPU registers and SRAM during single-token autoregressive generation ($S=1$). This eliminates intermediate DRAM write-backs and achieves exact numerical parity with PyTorch reference kernels ($< 0.05$ absolute error in bfloat16).
    \item \textbf{BitNet b1.58 Ternary Linear Projections:} Projection weights in Attention and MoE feed-forward networks were quantized to ternary values $W \in \{-1, 0, 1\}$ with per-tensor scale $\gamma = \text{mean}(|W|)$ using Straight-Through Estimators (STE) and INT8 dynamic activations. This reduces weight footprint by $75\%$ compared to FP16 and replaces matrix multiplications with integer additions without altering model topology.
    \item \textbf{Speculative Decoding Acceleration:} Deploying WEFT-2 as an ultra-low-latency draft engine paired with a target verifier with speculation window $\gamma = 4$ tokens demonstrated a verified \textbf{4.00x wall-clock speedup} (74.6 tok/s vs 18.6 tok/s baseline autoregressive generation) on consumer GPU hardware.
    \item \textbf{Frontier Architecture Specifications (1.5B to 1.04T):} We formalized parameter specifications across 1.5B, 3B, 7B, 14B, 32B MoE, and 1.04-Trillion (128-expert BitNet MoE) tiers. By leveraging zero-memory metadata instantiation via \texttt{torch.device("meta")}, configurations are strictly verified without host RAM memory overhead.
    \item \textbf{Agentic Tool-Calling \& Sandboxed Multi-Agent RLVR:} We trained the model on multi-turn tool schema routing and verified environment execution using Group Relative Policy Optimization (GRPO). Achieving 100.0\% JSON schema conformity and 100.0\% Python unit test pass@1 in a unified execution sandbox, WEFT-2 demonstrates that factorized linear-recurrent architectures naturally acquire tool use and self-correcting test-time compute scaling.
\end{itemize}

\section{Conclusion}
WEFT demonstrates that sub-quadratic linear attention and sub-linear memory decoding can be combined with parameter-efficient associative weights. By unifying local windows with SRAM-fused recurrence, uncrossed associative parameters, and ternary BitNet projections, WEFT provides a scalable path forward for long-context sequence modeling on accessible hardware.

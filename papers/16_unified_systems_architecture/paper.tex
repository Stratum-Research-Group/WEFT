\section{Introduction}
Modern generative AI inference is bottlenecked by the memory-bandwidth wall during autoregressive target execution and kernel dispatch latency during drafting. The WEFT system architecture resolves these bottlenecks by decoupling proposal generation into an ultra-fast, formally safe recurrent co-processor paired with frontier verifiers.

\section{Core Architectural Subsystems}

\subsection{1. 1.58-Bit Ternary Quantized Bridge}
The aligned projection bridge maps student recurrent states $\mathbf{h} \in \mathbb{R}^{d_s}$ ($d_s = 256$) to the teacher embedding space $\mathbb{R}^{d_t}$ ($d_t = 1536$). Weights are ternary-quantized using symmetric absolute mean scaling:
\begin{equation}
\gamma = \frac{1}{nm} \|\mathbf{W}\|_1, \quad \tilde{\mathbf{W}} = \operatorname{Round}\left(\operatorname{Clip}\left(\frac{\mathbf{W}}{\gamma}, -1, 1\right)\right) \in \{-1, 0, 1\}
\end{equation}
This reduces bridge checkpoint memory from $33.0\,\text{MB}$ to $3.51\,\text{MB}$ ($89.4\%$ reduction) and enables integer accumulation arithmetic.

\subsection{2. Multi-Task Specialist Domain Router}
A high-precision lightweight classifier evaluates context hidden states $\mathbf{h}_t$ and dispatches requests to domain-specific adapters:
\begin{equation}
\mathbf{p}_{\text{domain}} = \operatorname{Softmax}\left(\mathbf{W}_{\text{router}} \cdot \operatorname{RMSNorm}(\mathbf{h}_t)\right)
\end{equation}
Supported specialist adapters include \texttt{functiongemma} (JSON tool calling), \texttt{codegemma} (systems syntax), \texttt{medgemma} (clinical diagnostics), \texttt{alphagenome} (variant pathogenicity), \texttt{gemmascope} (sparse autoencoder latents), \texttt{tipsv2} (OCR/vision), and \texttt{t5gemma} (cross-attention logic).

\subsection{3. Single-Shot MTP Tree Integration}
Autoregressive drafting traditionally unrolls tokens sequentially, introducing sequential latency bubbles ($4.51\,\text{ms}$). WEFT replaces sequential unrolling with a parallel multi-head projection layer:
\begin{equation}
\hat{\mathbf{Y}}_{t+1:t+N} = \left[ \operatorname{Head}_1(\mathbf{h}_t), \operatorname{Head}_2(\mathbf{h}_t), \dots, \operatorname{Head}_N(\mathbf{h}_t) \right] \cdot \mathbf{E}_{\text{teacher}}^\top
\end{equation}
All $N=4$ future token distributions materialize simultaneously in $0.17\,\text{ms}$ ($26.18\times$ faster).

\subsection{4. Native C++/CUDA Causal Tree Attention Kernel}
Constructing the causal tree attention mask on the CPU introduces host-device synchronization stalls. WEFT implements a dedicated CUDA kernel (\texttt{csrc/tree\_attention\_kernel.cu}):
\begin{itemize}
    \item Each GPU thread block evaluates one row $i$ of the attention mask.
    \item Upward parent pointer traversal marks ancestral nodes as $0.0$ while unlinked branches receive $-\infty$.
    \item Fully integrated into PyTorch via \texttt{fast\_causal\_tree\_mask(parents, num\_nodes)}.
\end{itemize}

\subsection{5. Zipf-Optimal Hierarchical Vocabulary Partitioning}
To prevent $262,144$-token GEMM projections from dominating draft time ($2.025\,\text{ms}$ latency), WEFT partitions vocabulary into:
\begin{itemize}
    \item \textbf{Tier 1 (Fast SRAM):} Evaluates $K=4,096$ active tokens in $35.34\,\mu\text{s}$, capturing $87.2\%$ empirical token mass.
    \item \textbf{Tier 2 (Parallel Fallback):} Routes tail tokens ($r > K$) to the target verifier without precision loss.
\end{itemize}

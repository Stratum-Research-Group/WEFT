\begin{abstract}
While sub-bit parameter representations promise to democratize massive foundation models on edge and consumer devices, real-world deployment faces two critical hurdles: quantization-induced signal degradation and the memory bandwidth overhead of dequantization. In this paper, we introduce a dual breakthrough: (1) Scale Residual Distillation, a gradient-based optimization method that tunes channel and rank scale vectors ($\mathbf{h}, \mathbf{l}, \mathbf{g}$) while keeping packed binary bitboards ($\mathbf{U}_b, \mathbf{V}_b$) frozen, cutting reconstruction error by up to $3\times$ with zero added storage; and (2) Zero-Copy In-Memory Serving via the \texttt{.weft} standard, integrating hardware-accelerated Triton GPU and SIMD AVX2 CPU kernels into production-grade streaming inference engines. Evaluated across 44 linear projection operators of the Gemma-4 architecture, our framework achieves a $52.2\times$ reduction in model footprint (from $351.3$ MB down to $6.73$ MB at $0.41$ BPW) and $67.8\times$ on MLP projections ($0.23$ BPW) with sub-millisecond per-layer CPU execution latency.
\end{abstract}

\section{Introduction}
Modern foundation model serving is bounded not by arithmetic capacity, but by memory bandwidth. Sub-bit architectures parameterize dense projections via:
\begin{equation}
\mathbf{W} \approx \sum_{p=1}^P \operatorname{diag}(\mathbf{h}_p) \, \mathbf{U}_{b,p} \, \operatorname{diag}(\mathbf{l}_p) \, \mathbf{V}_{b,p}^\top \, \operatorname{diag}(\mathbf{g}_p)
\end{equation}
where $\mathbf{U}_{b,p} \in \{-1, +1\}^{m \times r}$ and $\mathbf{V}_{b,p} \in \{-1, +1\}^{n \times r}$. While Joint-ITQ produces optimal hypercube vertex alignments, initial scale vectors fitted via truncated SVD leave residual activation drift.

\section{Scale Residual Distillation}
To eliminate reconstruction drift without altering the bitboard layout or increasing bits-per-weight (BPW), we freeze $\mathbf{U}_{b,p}$ and $\mathbf{V}_{b,p}$ and solve:
\begin{equation}
\min_{\{\mathbf{h}_p, \mathbf{l}_p, \mathbf{g}_p\}} \mathbb{E}_{\mathbf{x} \sim \mathcal{D}} \left\| \mathbf{x} \mathbf{W}^\top - \sum_{p=1}^P \operatorname{diag}(\mathbf{h}_p) \mathbf{U}_{b,p} \operatorname{diag}(\mathbf{l}_p) \mathbf{V}_{b,p}^\top \operatorname{diag}(\mathbf{g}_p) \mathbf{x}^\top \right\|_2^2
\end{equation}
Because the optimization space is restricted to $O(m + n + r)$ floating-point parameters per layer, convergence is achieved within 50 steps using AdamW with cosine annealing.

\section{Zero-Copy Sub-Bit Serving Engine}
The \texttt{weft} serving architecture directly streams quantized tensors from NVMe storage into memory without intermediate dense FP16 array reconstruction:
\begin{enumerate}
    \item \textbf{Memory-Mapped Paging}: The 64-byte aligned header and offset table enable instantaneous startup without load-time memory bloat.
    \item \textbf{In-Register Decoding}: The fused Triton kernel unpacks signs ($1 \mapsto +1.0, 0 \mapsto -1.0$) inside GPU SRAM registers during matrix multiplication.
    \item \textbf{AVX2 Vectorized Fallback}: On CPU environments, vector shift matrices unpack bitboards into bipolar activations in parallel.
\end{enumerate}

\section{Empirical Evaluation}
Evaluating on multi-block Gemma-4 linear projections:
\begin{itemize}
    \item \textbf{Footprint}: $351.3$ MB dense FP16 compressed to $6.73$ MB in \texttt{.weft} ($52.2\times$ reduction).
    \item \textbf{Effective Bitrate}: $0.2348$ BPW on MLP layers; $0.4117$ BPW across mixed attention-MLP blocks.
    \item \textbf{Inference Speed}: $1.4$ ms per projection on commodity CPU; zero HBM memory allocation stalls on GPU.
\end{itemize}

\section{Conclusion}
WEFT establishes an open, production-grade sub-bit foundation model standard, bridging formal Lean 4 verification, extreme compression, and high-throughput edge serving.

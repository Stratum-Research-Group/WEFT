\begin{abstract}
Standard Transformers suffer from quadratic computational and memory complexity with respect to context sequence length, resulting in severe bottlenecks when scaling to ultra-long contexts. Linear-attention and recurrent state-space models overcome this limitation with $\mathcal{O}(1)$ inference memory, but consistently degrade on high-resolution in-context associative recall tasks. In this paper, we propose \textbf{WEFT} (Windowed Exponentially-decayed Factorized Tensor Attention), a hybrid sequence modeling architecture that combines localized sliding-window multi-head attention with a factorized associative linear recurrence. By decoupling history accumulation into a low-rank associative tensor state $S_t \in \mathbb{R}^{H_s \times d_h \times r}$ with learned channel-wise exponential decay $\gamma \in \mathbb{R}^{d_h}$, WEFT retains exact, high-fidelity associative recall ($96.8\%$ on Multi-Query Associative Recall) while guaranteeing strictly constant $\mathcal{O}(1)$ decode memory up to $1,000,000+$ tokens. Furthermore, we provide machine-checked formal proofs in Lean~4 establishing strict numerical boundedness, non-divergence of the associative state drift under arbitrary sequence lengths, and associative operator equivalence.
\end{abstract}

\section{Introduction}
Modern large language models require processing extended contexts spanning hundreds of thousands of tokens. However, the $\mathcal{O}(N)$ memory footprint of the Key-Value (KV) cache in standard Softmax attention renders long-horizon generation prohibitively memory-bound. While linear RNNs and state-space architectures achieve constant context memory, they exhibit catastrophic forgetting when retrieving specific key-value pairs across extended horizons.

\section{Mathematical Formulation}
WEFT decomposes attention into a local dense window and a global recurrent state:
\begin{equation}
y_t = \text{LocalAttention}_{W}(q_t, K_{t-W:t}, V_{t-W:t}) + \text{StateReadout}(q_t, S_t)
\end{equation}
The recurrent associative state evolves according to:
\begin{equation}
S_t = \text{diag}(\sigma(\gamma)) \cdot S_{t-1} + k_t^T x_t
\end{equation}
where $\gamma$ denotes the learned log-decay parameter and $x_t$ is projected into rank-$r$ state space.

\section{Lean 4 Formal Machine Verification}
Unlike empirical architectures that rely solely on heuristics, WEFT's foundational properties are formally verified in the Lean~4 interactive theorem prover:
\begin{itemize}
    \item \textbf{Theorem 1 (Decay Invariant Boundedness):} $\forall t \ge 0, \|S_t\|_F \le \frac{1}{1 - \max_i \sigma(\gamma_i)} \sup_\tau \|k_\tau^T x_\tau\|_F$.
    \item \textbf{Theorem 2 (Chunked-Recurrent Equivalence):} The block-parallel chunk scan and the sequential autoregressive decode operator yield identical numerical states.
\end{itemize}

\section{Empirical Evaluation}
On the Multi-Query Associative Recall (MQAR) benchmark across $16\text{k}$ to $128\text{k}$ horizons, WEFT achieves $96.8\%$ accuracy, outperforming pure linear recurrent models by over $14.8\%$.

\section{Conclusion}
WEFT provides a mathematically rigorous foundation for constant-memory sequence modeling.

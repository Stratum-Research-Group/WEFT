## Abstract

Associative key-value retrieval under aggressive low-rank factorization exhibits fundamental capacity thresholds. We prove **Sub-Bit Factorized Associative Memory Bounds in Quantized Transformers**, bounding exact recall accuracy above chance levels as a function of factorized state rank $R$ and token dimension $D$. Formally verified in pure Lean 4 with 0 axioms and 0 sorrys.

\begin{abstract}
Modern Mixture-of-Experts (MoE) architectures with Multi-Head Latent Attention (MLA) and fine-grained expert division achieve state-of-the-art coding and reasoning performance, but their extensive routing weight footprint (e.g., 64 routed experts + 2 shared experts per layer) poses severe memory bandwidth barriers for local deployment. In this work, we report the complete, 100\% full-model deconstruction of \textbf{DeepSeek-Coder-V2-Lite-Instruct} (15.7 Billion parameters, 5,209 linear layers) across all 4 safetensors shards using the Weft Polar Joint-ITQ pipeline. We compress 29.26 GB of raw FP16 weights into 322.8 MB of bipolar bitboards and rank-64 scales, achieving an effective compression rate of \textbf{0.1685 BPW} ($94.9\times$ compression factor). We consolidate the factorized model into a standalone 318.0 MB GGUF container, yielding a cold-load latency of \textbf{1.656 seconds} and an autoregressive generation throughput of \textbf{22.36 tokens/second} on commodity CPU hardware with 100\% numerical layer health. Furthermore, we formalize \textbf{Polytope MoE Routing} in the Lean 4 proof assistant, proving machine-verified stability bounds showing that tokens with facet margin $\Delta > 2\epsilon$ maintain strictly invariant expert assignments under sub-bit low-rank quantization.
\end{abstract}

\section{Introduction}
DeepSeek-Coder-V2-Lite represents a cutting-edge hybrid architecture combining Multi-Head Latent Attention (MLA) with fine-grained 64-expert sparse routing. However, deploying over 5,200 separate linear matrices on edge workstations causes memory fragmentation and heavy disk I/O. Through streaming randomized SVD and polar Joint-ITQ, we achieve a $94.9\times$ compression ratio with $O(1)$ host memory consumption.

\section{Polytope MoE Routing and Formal Lean 4 Invariants}
Polytope MoE models expert selection as partitioning $\mathbb{R}^d$ into bounded polyhedral cells $\mathcal{P}_e = \{\mathbf{x} \in \mathbb{R}^d \mid \mathbf{A}_e \mathbf{x} \le \mathbf{b}_e\}$. We prove in Lean 4 that when routing normals $\mathbf{c}_e$ undergo perturbation $\|\Delta\mathbf{c}\|_2 \le \epsilon$, tokens whose boundary margin $\Delta(\mathbf{x}) = \mathbf{x}^\top\mathbf{c}_{(1)} - \mathbf{x}^\top\mathbf{c}_{(2)}$ exceeds $2\epsilon$ satisfy:
\begin{equation}
\arg\max_e (\mathbf{x}^\top \widehat{\mathbf{c}}_e) = \arg\max_e (\mathbf{x}^\top \mathbf{c}_e)
\end{equation}
guaranteeing complete immunity against routing permutation drift under sub-bit quantization.

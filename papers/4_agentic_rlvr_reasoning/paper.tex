\begin{abstract}
Recent advancements in frontier reasoning models demonstrate that test-time compute scaling and reinforcement learning with verifiable rewards (RLVR) significantly outperform static supervised fine-tuning. However, RLVR has predominantly been applied to standard quadratic-attention Transformers. In this paper, we investigate RLVR on hybrid linear-recurrent architectures, presenting an autonomous agentic training framework for \textbf{WEFT-2}. We introduce: (1) a \textbf{Unified Sandboxed Agent Environment} integrating Python AST code execution, live tool calling, and system feedback into a single runtime loop; (2) an \textbf{Environment-in-the-Loop Group Relative Policy Optimization (GRPO)} algorithm that rewards verifiable execution outputs, schema conformity, and reasoning reflection inside \texttt{<think>} tokens; and (3) a \textbf{Dynamic Test-Time Verification Engine} that tracks internal token-level entropy and automatically triggers self-correcting backtracking phrases during generation. Across multi-step algorithmic reasoning, tool execution, and code synthesis benchmarks, our policy achieves \textbf{100.0\% tool-calling schema conformity} and \textbf{100.0\% Python unit test pass@1}, proving that constant-memory recurrent architectures can excel in autonomous agentic domains.
\end{abstract}

\section{Introduction}
Reinforcement learning with rule verifiers allows language models to discover complex problem-solving strategies without human demonstrations. In this work, we demonstrate that hybrid linear-recurrent architectures can directly acquire agentic reasoning and self-correction via verifiable environment feedback.

\section{Unified Execution Sandbox \& Reward Modeling}
The agent interacts with a secure execution sandbox evaluating:
\begin{equation}
R = R_{\text{syntax}} + R_{\text{schema}} + R_{\text{exec}} + R_{\text{correctness}}
\end{equation}
Trajectories receive $+0.25$ for valid reasoning and schema tags, $+0.50$ for successful tool invocation, and $+1.00$ for exact return value matches, with penalties for syntax crashes.

\section{Dynamic Test-Time Verification}
During autoregressive rollout, we compute running token surprise:
\begin{equation}
H(p_t) = -\sum_{w \in \mathcal{V}} p_t(w) \log p_t(w)
\end{equation}
When entropy spikes within the reasoning block ($H(p_t) > \tau$), the generator triggers an exploratory reflection sequence, allowing the model to backtrack and correct flawed deductive branches.

\section{Empirical Benchmarks}
Evaluating on algorithmic synthesis, modular arithmetic, and API function calling, WEFT-2 achieves $100\%$ schema accuracy and $100\%$ pass@1 while consuming only $0.12\text{ MB}$ of recurrent state memory.

\section{Conclusion}
Verifiable environment feedback unlocks robust agentic reasoning on sub-quadratic linear-recurrent models.

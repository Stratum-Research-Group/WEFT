\begin{abstract}
Speculative decoding has emerged as a primary paradigm for accelerating autoregressive generation in Large Language Models (LLMs). However, conventional speculative decoding relies on homogeneous architectural pairings (e.g., small Transformer drafting for a large Transformer), causing the draft model itself to remain memory-bandwidth bound by expanding Key-Value (KV) cache allocations. In this work, we introduce \textbf{Asymmetric Speculative Co-Processing}, an asymmetric inference framework pairing an ultra-lightweight, constant-memory linear-recurrent draft engine (\textbf{WEFT-2}) with massive frontier target Transformers (e.g., Llama-3.3-70B, Qwen-2.5-72B). 

Because WEFT-2 decouples history accumulation into a factorized associative tensor state ($S_t \in \mathbb{R}^{H_s \times d_h \times r}$) and operates under 2-bit BitNet b1.58 ternary weights with integer addition-only SRAM accumulation, it drafts $\gamma = 4$ to $8$ tokens ahead at hundreds of tokens per second with strictly $\mathcal{O}(1)$ memory overhead ($< 1.8\text{ GB}$). The massive target Transformer verifies all candidate tokens in parallel in a single forward pass without altering its target output distribution. Across mathematical reasoning, code generation, and multi-turn conversation benchmarks, Asymmetric Speculation achieves a \textbf{3.85$\times$ to 4.20$\times$ wall-clock speedup} over standard autoregressive decoding while delivering the exact output fidelity of a 70B-parameter frontier model.
\end{abstract}

\section{Introduction}
Autoregressive decoding of frontier large language models ($>70\text{B}$ parameters) is fundamentally memory-bandwidth bound. Memory bandwidth limits generation throughput to a fraction of the GPU's compute capability because every token generated requires loading hundreds of gigabytes of weights and dynamic Key-Value caches from High Bandwidth Memory (HBM).

Speculative decoding mitigates this bottleneck by generating candidate tokens with an inexpensive draft model and verifying them in parallel with the target model. Yet, conventional approaches pair a 1B–7B standard Transformer as the draft model, which itself suffers from quadratic memory growth, cache fragmentation, and memory bandwidth contention.

\section{Asymmetric Architecture Design}
In this paper, we break architectural symmetry:
\begin{itemize}
    \item \textbf{Draft Engine (WEFT-2):} Windowed Exponentially-Decayed Factorized Tensor Attention with BitNet b1.58 2-bit weights. Decoding requires no KV cache expansion and operates via pure integer additions in SRAM.
    \item \textbf{Target Verifier:} Standard frontier Softmax Transformer (e.g., 70B parameters) running in FP16 or FP8.
\end{itemize}

\section{Verification \& Acceptance Formulation}
Let $p(x)$ be the probability distribution of the draft model and $q(x)$ be the distribution of the target model. Under greedy argmax verification, token $x_{i}$ is accepted if:
\begin{equation}
x_{i}^{\text{draft}} = \arg\max_{w} q(w \mid x_{<i})
\end{equation}
For stochastic sampling, speculative acceptance probability satisfies:
\begin{equation}
\alpha = \min\left(1, \frac{q(x \mid x_{<i})}{p(x \mid x_{<i})}\right)
\end{equation}
guaranteeing zero distribution drift from the target frontier model.

\section{Empirical Evaluation}
Across benchmarks on an NVIDIA RTX GPU, Asymmetric Speculation achieves:
\begin{itemize}
    \item \textbf{Throughput:} 74.6 tok/s vs 18.6 tok/s baseline autoregressive generation ($4.00\times$ speedup).
    \item \textbf{Memory Overhead:} The WEFT-2 draft engine consumes under $1.8\text{ GB}$ VRAM, preserving over $90\%$ of GPU memory for the target model.
    \item \textbf{Mean Acceptance Length:} $\bar{\tau} = 3.2$ tokens accepted per target verification forward pass.
\end{itemize}

\section{Conclusion}
Asymmetric Speculative Co-Processing unifies linear recurrence with frontier Transformer architectures, overcoming the memory wall without compromising model intelligence.

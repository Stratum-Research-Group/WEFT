\begin{abstract}
Production large language model (LLM) serving frameworks, such as vLLM, rely on paged memory allocation to mitigate memory fragmentation and enable dynamic prefix caching. Under paged allocation, continuous sequence positions are mapped into non-contiguous physical memory blocks indexed via lookup tables. On host CPU silicon, traversing paged structures during Flash-Attention typically induces severe pointer chasing and scattered memory access penalties. In this paper, we present an in-register paged Flash-Attention kernel optimized for AVX-512 F/DQ registers on AMD Zen 4 microarchitectures. By combining dynamic block-table address translation with in-register online softmax rescaling and vectorized fused multiply-accumulates, the kernel evaluates self-attention over arbitrary paged KV-cache configurations without data relocation or tensor consolidation. We formally verify block offset bounds, token index reconstruction, and memory stride non-interference in Lean 4 without non-standard axioms or \texttt{sorry}, and demonstrate exact single-precision parity against contiguous references.
\end{abstract}

\section{Introduction}
To eliminate external memory fragmentation, inference engines store KV-cache tensors in fixed-size blocks (e.g. $B=16$ tokens). A block table $\mathcal{T}$ translates logical sequence position $i$ into physical block index $b$ and offset:
\begin{equation}
b = \mathcal{T}[\lfloor i / B \rfloor], \quad \text{offset} = i \pmod{B}
\end{equation}

Evaluating Flash-Attention directly on paged caches eliminates intermediate contiguous reassembly buffers, avoiding DRAM roundtrips.

\section{AVX-512 Kernel Architecture}
The kernel evaluates attention across block entries:
\begin{enumerate}
    \item \textbf{Dynamic Stride Lookup}: Translates $(b, \text{offset})$ directly to physical memory offsets $b \cdot (B \cdot d) + \text{offset} \cdot d$.
    \item \textbf{Vectorized Scoring}: Projects $\mathbf{q} \cdot \mathbf{k}_i$ across 16-float lanes using \texttt{\_mm512\_fmadd\_ps}.
    \item \textbf{In-Register Rescaling}: Updates running maximum $m^{(k)}$ and partition sum $S^{(k)}$ without spilt buffers.
\end{enumerate}

\section{Lean 4 Formal Certification}
Four core algebraic theorems are certified in \texttt{formal/real\_conjectures/PagedCacheInvariants.lean}:
\begin{itemize}
    \item \textbf{Theorem 1 (\texttt{paged\_cache\_offset\_bound})}: Certifies $0 \le i \pmod{B} < B$.
    \item \textbf{Theorem 2 (\texttt{paged\_cache\_offset\_within\_block})}: Bounds within-block offsets.
    \item \textbf{Theorem 3 (\texttt{paged\_cache\_reconstruction\_invariant})}: Proves $B \cdot (i / B) + (i \pmod{B}) = i$.
    \item \textbf{Theorem 4 (\texttt{paged\_cache\_stride\_non\_interference})}: Proves distinct blocks $b_1 \ne b_2$ yield non-overlapping physical memory addresses.
\end{itemize}
All theorems verify cleanly with 0 non-standard axioms and 0 \texttt{sorry}.
